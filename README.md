 Ceylon Escape – Travel Booking Website

Ceylon Escape is a modern, responsive travel and tourism booking website developed as part of a Full-Stack Developer Intern Technical Assessment.

Technologies Used
- React
- TypeScript
- Tailwind CSS
- Vite
- React Router
- Lucide React

 Features
- Responsive Home Page
- Explore Destinations Page
- Destination Details Page
- Destination Search and Filtering
- Image Gallery
- Booking Form with Validation
- Automatic Price Calculation
- Demo Booking Confirmation

How to Run

1. Install dependencies:
   `npm install`

2. Start the development server:
   `npm run dev`

3. Build the project:
   `npm run build`

 AI Tool Usage

OpenAI ChatGPT was used for development guidance, code examples, component structure, styling, and debugging assistance.

 Note

This is a frontend demonstration project using sample travel data. No real bookings or payments are processed.
